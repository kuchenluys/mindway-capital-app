# 💎 Mindway Capital - Plataforma Integral

## 📋 Descripción General

**Mindway Capital** es una plataforma web integral que integra cuatro pilares principales:

- 💰 **Gestión de Capital e Inversiones** - Trading, análisis de posiciones, estrategias
- 🧠 **Desarrollo Personal** - Crecimiento consciente, mindfulness, productividad
- 💪 **Biohacking** - Optimización del cuerpo y rendimiento físico
- 📚 **Educación** - Cursos, talleres, metodologías exclusivas
- 🌱 **Comunidad** - Red de traders y emprendedores con visión compartida

## ✨ Versiones Disponibles

**Archivo**: `design/mindway-unified.html`

**Cómo usar**:
1. Abre el archivo en navegador
2. Usa demo@mindway.com / demo123
3. Elige rol: Usuario o Administrador

### 2. **Admin Panel Completo** (PANEL DE CONTROL)
**Archivo**: `admin/mindway-admin-complete.html`

**Herramientas Incluidas**:
- ✅ **Dashboard** - Métricas principales (usuarios, ingresos, retención)
- ✅ **Analytics Avanzado** - Gráficos, dispositivos, conversión

- ✅ **Gestor de Archivos** - Subir materiales, PDFs, videos
- ✅ **Panel de Usuarios** - Crear usuarios, asignar roles, permisos

**Cómo usar**:
1. Abre el archivo en navegador
2. Usa admin@mindway.com / admin123
3. Accede a todas las herramientas desde el sidebar izquierdo
4. Personaliza la plataforma según tus necesidades
