## 🚀 QUICK START

### Setup Local (30 min)

```bash
# Clone
git clone https://github.com/mindway/mindway-capital.git
cd mindway-capital

# Backend
cd backend && npm install && npm run dev

# Frontend (new terminal)
cd frontend && npm install && npm run dev

# Mobile (new terminal)
cd mobile && npm install && npm start
```
